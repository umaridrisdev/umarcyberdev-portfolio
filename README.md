## 🚀 Local Development & Build

To run the portfolio locally:

```bash
npm install
npm run dev
```

To compile the production build:

```bash
npm run build
```

The output will be saved to the `dist/` directory, ready for deployment to GitHub Pages, Vercel, or Netlify.
